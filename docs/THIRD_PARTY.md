# Third-party components, licences and AI disclosure

This file lists every library, tool, service and asset that Aether uses or
ships, with its exact version, licence, source and credit line, and discloses
where AI was used.

Package versions and licences were read on 2026-10-21 from `package-lock.json`
and cross-checked against each installed `node_modules/<pkg>/package.json`
and its LICENCE file (all versions and licence fields match). Asset licences
and checksums were read from `assets/sources.json`, `assets/manifest.json`,
`assets/characters.json`, `assets/creatures.json`, `assets/voxel-textures.json`
and `apps/studio/public/blocks/block-materials.json`, and re-checked against the
source archives kept in the local asset cache where they are present (see each
section).

Aether's own code is [MIT](../LICENSE) (© 2026 Aether contributors). All 15
workspace packages (`apps/bridge`, `apps/cli`, `apps/server`, `apps/studio` and
`packages/agent`, `arch`, `assets`, `core`, `logic`, `physics`, `playtest`,
`procgen`, `render`, `verifier`, `voxel`) are private and MIT-licensed.

**Summary.**

- Code that ships to users (the browser bundle, the server, the CLI and the
  local bridge) is under **MIT, Apache-2.0, ISC, BSD-2-Clause or
  BSD-3-Clause**.
- The only licence outside that set is **MPL-2.0** (lightningcss), a build
  tool that is never shipped. See [Flags](#flags-and-notes).
- Fonts: **SIL Open Font License 1.1**.
- Third-party media: **CC0-1.0** (Kenney, Poly Haven, ambientCG, Quaternius
  Farm Animals, the Fox model), **CC-BY-4.0** (the Fox rig, animation and glTF
  conversion, and the LG range cooker from NVIDIA SimReady Central, credited) and **MIT** (Microsoft Rocketbox characters and
  motions).
- Nothing is GPL, LGPL, AGPL, non-commercial, no-derivatives, share-alike,
  personal-use-only, evaluation-only or source-available.

  download cap (photoscanned, 1M+ triangles); the procedural trees cover forests.
- Poly Haven kit sheets that lay many pieces side by side (apartment and factory facades, fort walls, pier,
  electricity poles, pipe and duct sets, street bench parts) and cut-out plant sheets (grass, moss, shrubs, flowers)
  whose single objects are spread over several metres; stumps and root clusters that read as rocks.
- Sketchfab (CC0 filter): the search API lists CC0 models, but download needs an account token and each model's
  licence is the uploader's claim, so nothing is fetched automatically; the top results are museum scans of 60k to
  460k triangles.
- Objaverse: licences are per object and inherited from Sketchfab, many are CC-BY-SA, NC or unclear, and a number are
  AI-generated; no per-object CC0 allow-list was built, so none shipped.
- KayKit (CC0 `LICENSE.txt` in each GitHub repository, for example Space Base Bits and Medieval Hexagon Pack):
  accepted as a source, not yet built, because the repositories are not zip archives on an allowed host.
- Smithsonian Open Access 3D: CC0 scans of museum objects of 100k to millions of triangles; none useful as props.
- Quaternius: unchanged, see [Quaternius licence check](#animals-from-third-parties).
- ambientCG: CC0 and already the source of the 23 photo finishes; further terrain sets would need new `material.finish`
  names in the core schema and renderer, which this change does not touch.

## Textures and materials

**GPU-compressed twins.** `assets/lib/k/<name>.<hash>.glb` are the library models of `assets/lib/m/` and `assets/lib/c/` with their images re-encoded as KTX2 (Basis Universal) by KTX-Software; `apps/studio/public/blocks/block-{albedo,normal,orm}.ktx2` are the block sheets as array textures. They are derivatives of the same sources and carry the same licences and credits as the files they were made from (`assets/ktx2.json` and `block-ktx2.json` record each source's SHA-256).

**Photo finish maps.** `assets/lib/x/` holds the ambientCG maps of the photo finishes converted by `scripts/assets/materials.ts` (colour pattern ratio, packed ORM, normal) as 512 px WebP, plus a 256 px WebP set of each; they are derivatives of the CC0 sources below and carry their licence and credit. They are encoded by the build's headless Chromium (libwebp); no further third-party code is involved. They are not KTX2 twins: the renderer decodes finish maps to pixels and packs them into its own texture arrays, so a GPU-compressed container would be transcoded back to pixels on load.

**Reduced skies.** `assets/lib/h/<id>.512.<sha8>.hdr` is each Poly Haven HDRI below at half width and height (2 x 2 average of linear radiance, `scripts/assets/hdri.ts`, this project's code), used when a sky only lights the scene. CC0-1.0, same credit as the full file.

## Reference and inspiration only (no code copied)

The following works informed ideas or algorithms. No source code, models,
weights, datasets, prompts, shaders or assets were copied from any of them;

**Software studied as a reference.**

- [Pascal Editor](https://github.com/pascalorg/editor) (MIT, © Pascal Group
  Inc.) was studied for an architectural editor's user experience and data
  model: the site / building / level / wall / slab / opening / roof / zone /
  item vocabulary, wall drafting with mitred joins, room labels with a
  coloured dot and the area, level selectors, cutaway / exploded /

  [Code adapted from MIT-licensed projects](#code-adapted-from-mit-licensed-projects);
  Aether takes no assets or materials from Pascal (see that section).

  ideas only (plan-to-3D reveal, ink-on-paper drawing, golden-hour staging).
  None of its code, shaders or files were used.
- Project Nayuki's QR Code generator (MIT) informed the structure of the QR
  encoder; the encoder was written for Aether from ISO/IEC 18004.
- `@sparkjsdev/spark` (MIT) was evaluated from its package metadata only
  (`experiments/gaussian-splats`) and is not installed.
- [Yuka](https://github.com/Mugen87/yuka) (MIT, © Mugen87) was read for its
  steering behaviours (arrive, wander, separation, cohesion, alignment); the
  formulas are Reynolds' and Buckland's, rewritten in
  `packages/logic/src/npc/steering.ts` on Aether's seeded random stream (Yuka's
  wander draws from `Math.random`). Not installed; no code copied.

  was evaluated for multi-floor NPC navigation from its npm package: 2.2 MB
  unpacked (534 kB main bundle), last release 2026-05-06, 0.x. It builds a
  navigation mesh from triangle soup, which the logic runtime does not have (it
  sees the document and collider bounds), and its queries return fresh objects
  and arrays. Not installed: the existing grid was extended to floors linked by
  stairs instead (ARCHITECTURE section 37).
- The game-feel and level-pacing notes of `gamedev-skills/awesome-gamedev-agent-skills`
  (Apache-2.0) informed the feel layer's design (several small responses within about
  a tenth of a second, trauma-squared camera shake, hit-stop, importance tiers, the
  picture moves and the body does not; teach, then test; a calm stretch before the
  climax). The presets, wording and code are Aether's own; no text was copied.

  dependency) were read as references for the effect presets (`packages/render/src/vfx/`).
